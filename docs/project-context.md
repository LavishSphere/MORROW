# MORROW — Project context

**Working name:** MORROW  
**Tagline:** Make tomorrow possible.  
**Event / track:** WHACK 2026 · Better Worlds (Social Impact)  
**Showcase:** Wellesley, MA (compact area near Wellesley College)

## North star

Win Better Worlds with a civic tool that is aesthetically unforgettable **and** substantively useful: observe → intervene → measure → advocate.

**Definition of done:** An unfamiliar judge opens a public URL, understands the issue, applies at least one intervention, sees a valid modeled before/after, and exports a credible proposal — without help.

## Non-negotiables

- Route math and evidence labels are code/data — never invented by Gemini.
- Evidence status (`verified` | `community_reported` | `illustrative`) stays honest; illustrative Wellesley scenarios are labeled as simulation.
- Public demo: no login or judge credentials.
- Prefer one exceptional Wellesley loop over unfinished multi-city scope.
- Cut order if behind: extra cities/animations → live Tiger Data; keep packaged dataset, route engine, proposal + Gemini-or-template.
